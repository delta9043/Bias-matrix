Abstract

초록

대규모 데이터를 모델에 학습시키거나 LLM 임베딩으로 바꾸어 신경망으로 분석하면 데이터의 편향이 결과에 그대로 반영되게 된다. 기존 대부분의 데이터 분석은 해당 편향을 간과하거나, LLM으로 증강한 비편향 데이터로 학습하여 데이터의 편향 문제를 해결하고자 한다. 하지만 LLM의 블랙박스 성질 때문에 비편향 데이터가 실제로 정당하게 합성되었는지는 의문이 남는다. 본 논문은 스펙트럼 편집을 통한 편향 제거 방법인 편향 행렬 편집법(Bias-Matrix Editing, BME)과, 이를 활용한 데이터 증강법인 편향 행렬 증강법(Bias-Matrix Augmentation, BMA)을 제안한다. 편향은 데이터 행렬 \(X\) 대신 편향이 존재하는 것으로 의심되는 성분만 모은 조건부 편향 행렬 \(B\)의 일부 특이값을 0으로 만들어 제거한다. 구체적으로 데이터의 특징별로 임베딩의 평균을 구하고, 편향이 발생한 특징들이 해당 그룹 안의 평균과의 차이를 열로 쌓아 \(B\)를 만든 뒤, \(B\)를 SVD하여 얻은 특이방향의 성분을 임베딩에서 사영으로 지운다. 이 방법을 Bias in Bios 약력 39.6만 건에 적용한 결과 정확도 손실 0.7%p를 기록하면서 성별 간 재현율 격차가 54% 줄었으며, 각 직업의 소수 성별 재현율을 약 5%p 올렸다. 또한 같은 편향 행렬을 활용하여 데이터 증강법 BMA를 만들었다. BMA는 \(B\)의 편향 평균 차이만큼 임베딩을 옮긴 복사본을 데이터 특징들이 독립이 되기 위한 필요한 최소한의 칸에만 더한다. BMA를 쓰면 반사실 증강(CDA)의 0.224배 분량의 데이터와 정확도 손실 0.6%p로 그룹 간의 편향 격차가 CDA의 30%보다 높은 54% 줄어든다. 또한 BME는 이미 학습된 모델에도 재학습 없이 적용할 수 있으며, 이때 정확도 손실 1.8%p로 편향 격차가 62% 줄어든다.

Results

실험 결과

BME 결과

BME는 정확도 손실 0.7%p로 재현율 격차를 54% 줄이며, 학습 데이터의 편향 강도가 달라져도 재현율 격차가 거의 변하지 않는다.

BMA 결과

BMA는 CDA의 0.224배 분량의 데이터로 재현율 격차를 54% 줄이며, 이때 정확도 손실은 0.6%p이다.

한국 공공데이터에 대한 적용 결과

위해위험 소비자상담 내역은 공정거래위원회가 공공데이터포털에 공개한 1372 센터의 상담 기록 104,552건이다. 상담의 제목과 본문으로 품목 대분류 15종을 예측하며, 그룹은 판매방식(일반 판매, 비대면 판매)이다.

한국 공공데이터에서도 BME는 재현율 격차를 29%, BMA는 12% 줄였으며, 그룹이 셋인 경우에도 같은 방식으로 적용되었다.
